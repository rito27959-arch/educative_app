usage: rive COMMAND

commands:
  create                    scaffold a project (rive.yaml, scene.rml, AGENTS.md, CLAUDE.md)
  <project-dir>             preview - open the scene in a window sized to the
                            artboard, rebuilding as you edit; runs until closed
                            (dir defaults to .)
  login                     sign in with your Rive account
  logout                    sign out
  whoami                    show who you're signed in as
  docs                      the documentation; new to Rive, start here
  samples                   pick a runnable example project and copy it
  schema                    look up types
  inspect                   print the resolved scene
  push                      upload to a file in your Rive account (not a preview)
  pull                      overwrite the project from its Rive file
  library                   publish the project's file as a library others
                            can import from, and find the ones it can import
  ls                        list the projects and files in the current
                            workspace of your Rive account
  workspace                 show or switch the current workspace
  open                      open a Rive file in the web editor
  build                     ship the project as an Android or iOS app
  aot                       compile the scripts in .riv files for an app's build
  doctor                    check the environment: version, auth, ports, project, devices
  lsp                       language server over stdio, for editor integrations
  update                    install the latest published CLI
  switch                    pick a CLI version, or select one by name
  uninstall                 remove a cached CLI version, or pick one
  analytics                 show or set usage analytics (on|off)

  rive --version            print version and exit

<project-dir> flags:
  --init                    write rive.yaml if missing, then continue
  --verify                  check the project without writing a .riv;
                            exit 1 on errors
  --once                    write an unsigned .riv; exit 1 on errors
  --keep-unstartable        a script module that fails to start here only
                            warns, and a capture boots it anyway, for
                            fixtures that test the failure
  --publish[=<target>]      local (default): write a signed .riv to disk; web:
                            build, sign and publish a page. Needs `rive login`;
                            exit 1 on errors
  --unpublish=<target>      web: take the page down; its name frees up
  --list-published[=<target>]
                            bare: where this project is published, local and web;
                            =local: the build directory only; =web: every page
                            live for the team
  --team=<id>               applies to --publish=web, --unpublish=web and
                            --list-published=web: the team that owns the page,
                            `pages.teamId` in `rive.yaml`; without it a
                            single team is picked automatically and several
                            open a picker
  --output-dir=<directory>  override rive.yaml output.dir for local publishing or listing
                            relative to the project; does not change rive.yaml
  --name=<name>             applies to --publish=web and --unpublish=web: the
                            page to publish or take down, lowercased to a slug
                            (--publish=web default: `pages.name`, then project;
                            --unpublish=web default: `pages.name` only)
  --drawer=<mode>           applies to --publish=web: docked, hidden or none,
                            how the page starts its controls (default:
                            the player's own)
  --no-wait                 applies to --publish=web: print the url without
                            waiting for it to go live
  --yes, -y                 applies to --unpublish=web: skip the confirmation
  --test                    run Tests scripts; exit 6 on failed cases and 1
                            on build errors
                            (--aot runs them on compiled code)
  --rev=<path>              also write an editor .rev; needs `rive login`
                            (with --once or --publish)
  --screenshot[=<p>]        build, render one frame headless, write a png
                            (defaults to build/<name>.png)
  --render-audio[=<p>]      build, run headless with no audio device, write what
                            the scripts' audio processors render as a 32 bit float
                            wav, for as long as the --advance steps add up to
                            (defaults to build/<name>.wav)
  --audio-rate=<Hz>         the sample rate --render-audio renders at (default:
                            48000)
  --audio-channels=<N>      the channels --render-audio renders (default: 2)
  --advance=<N|Ns|Nms>
                            step N frames at 60fps, or that much animation time,
                            at this point in the --pointer/--semantic-action
                            sequence; repeatable; one after the last gesture is the
                            settle before the capture; needs --screenshot,
                            --semantics, --data-dump or --render-audio
  --probe=<x,y>             print the capture's colour there, as
                            AARRGGBB like a colorValue; repeatable; needs
                            --screenshot
  --compare=<png>           print how many pixels differ from an
                            earlier capture; needs --screenshot
  --scale=<f>               shrink the written png by f (0 to 1), e.g.
                            0.5 for a layout check; needs --screenshot
  --seed=<N>                the seed scripts' math.random starts from
                            (default 1); captures are repeatable either way,
                            this picks a different sequence; needs --screenshot,
                            --semantics or --data-dump
  --viewport=<WxH>          the size the scene is laid out at: the
                            capture size with --screenshot/--semantics/
                            --data-dump,
                            the window size when watching. Defaults to the
                            artboard's own
  --no-settle-lanes         applies to --screenshot, --semantics, --data-dump
                            and --render-audio:
                            do not wait after each frame for the jobs scripts
                            started to finish and their workers to go idle
  --bench=<frames>          build with the scripts a publish ships, time that
                            many frames headless, report advance/render stats
                            and wasm memory growth
  --gpu-manifest=<path>     write the GPU objects scripts create as WebGPU
                            descriptors for tools/webgpu_validate; runs headless
  --job-threads=<N>         threads AnimaScript jobs run on (default: one fewer
                            than the cores, at most 6)
  --worker-threads=<N>      threads AnimaScript workers share (default: one fewer
                            than the cores, at most 4)
  --data=<path=value>       set a view model property before the scene runs;
                            after a --pointer/--advance/etc., a step at that
                            point in the sequence instead, then a frame;
                            repeatable
  --data-dump[=<p>]         build, run headless, write the bound view model
                            values, the globals and the nested artboards as JSON,
                            to a path or - (or stdout) for standard output
                            (defaults to build/<name>.data.json); combines with
                            --screenshot, --viewport, --data, --pointer, --advance
  --data-dump-filter=<paths>
                            keep only these property paths, comma separated,
                            globs allowed (battery/*,score)
  --data-dump-every=<N|Ns|Nms>
                            sample every N frames (or that much animation time,
                            1s, 250ms) rather than once at the end, as JSON
                            Lines: a header, a frame-0 baseline, then only what
                            changed. Must be a whole number of frames at 60fps.
                            Includes the frames gestures advance internally
  --gamepad=<event>         synthesise a gamepad event: connect, disconnect,
                            button@<name|N>:down|up|<0..1>,
                            axis@<name|N>:<-1..1>; repeatable. Names are the
                            W3C standard ones (south, west, dpadLeft, leftX);
                            a bare index is W3C 0-based
  --key=<key[:phase][+mods]>synthesise a keystroke through the real dispatch path:
                            right, a:down, escape:up, tab:down+shift;
                            phase is down|repeat|up, or press (down then up)
                            and is what it defaults to. Repeatable, in order
                            with --pointer and --advance. Keys only reach what
                            holds focus; with nothing focused it says so
  --pointer=<kind@x,y>      synthesise down|up|move|exit|click at artboard coords;
                            repeatable; drag@x1,y1>x2,y2[:steps] presses,
                            drags and releases; wheel@x,y:dx,dy[:notches] and
                            trackpad@x,y:dx,dy[:steps] scroll the content by
                            dx,dy (a drag's sense: -y reveals what is below),
                            the swipe then flinging; needs --screenshot,
                            --semantics or --data-dump
  --touch=<kind[:id]@x,y>   synthesise a finger: down|up|move|tap, each id its
                            own pointer (default 0), a lift also its exit;
                            drag@x1,y1>x2,y2+x3,y3>x4,y4[:steps] drags fingers
                            id, id+1, ... together (a pinch); repeatable, in
                            order with --pointer; needs a capture like --pointer
  --semantics[=<p>]         build, run headless, write the accessibility tree
                            as JSON, to a path or - (or stdout) for standard
                            output (defaults to build/<name>.semantics.json);
                            combines with --screenshot, --viewport, --data,
                            --pointer, --advance
  --semantic-action=<type@label>
                            fire tap|increase|decrease on the node with that
                            accessibility label; repeatable, in order with --pointer
                            and --advance;
                            needs --screenshot, --semantics or --data-dump
  --artboard=<name>         artboard to show on launch
  --fit=<mode>              how the artboard maps into the view:
                            fill, contain, cover, fit-width, fit-height, none,
                            scale-down, layout (default). layout resizes the
                            artboard to the window and reflows it; the rest
                            scale it at its authored size
  --serve[=port]            also push builds to connected players
  --headless-serve          serve with no local window
  --device=<name>           serve, and put the player on that device, emulator or simulator
  --android, --ios          the same on the first device of that kind
  --device-backend=<gl|vulkan>
                            how an Android device draws
  --aot                     compile scripts ahead of time, here and on devices
  --debug[=port]            host a script debugger for VS Code
  --audio-buffer=<frames>   the watch window's audio device buffer, 16 to 8192
                            frames (default: rive.yaml audioBuffer, else the
                            device's); bigger keeps a heavy processor from
                            dropping out, at the cost of latency
  --no-status-bar           hide the window's stats strip (paid plans)
  --quiet                   no terminal log but script errors
  --optimize                faster script compile, harder to debug;
                            AnimaScript drops its debugger line probes and
                            runs several times faster, for timing and long tests
  --allow-net               let scripts fetch() https: URLs; without it
                            fetch rejects with "disabled"
  --define=<NAME[=n]>       set an AnimaScript build constant (default 1);
                            repeatable, overrides rive.yaml defines
  --format=json             with --once/--verify/--publish/--test: one JSON
                            report envelope on stdout (--json is the same)

create:
  rive create               prompt for a name, then write that directory
  rive create <dir>         write the project in <dir> (`.` is the cwd)
  rive create [dir] --from-rev=<file.rev>
                            convert an editor .rev into a project: scene.rml
                            with its scripts and assets as files (dir must
                            be empty or new)
  rive create [dir] --from-remote-file[=<fileId>]
                            the same, on a file downloaded from your Rive
                            account; without an id, pick one. rive.yaml
                            records it, so `rive push <dir>` updates it

schema:
  rive schema <Type>        properties of a type (inherited included)
  rive schema --search <t>  find a type or property by name, then pick
                            one to describe

  --list                    pick a type to describe
  --animatable              only properties that can be keyed
  --bindable                only properties that can be data bound
  --all                     include editor-only properties

docs:
  rive docs                 the documentation index; new to Rive, start here
  rive docs <topic>         one topic, e.g. layout or luau/protocols

  --list                    every topic with a description
  --search <text>           lines matching text, every topic
  --pick                    with --list or --search, pick one to read
  --path                    the docs directory on disk

samples:
  rive samples              pick one and copy it into a new directory;
                            without a picker, every sample with a
                            description

  --path                    the samples directory on disk

inspect:
  rive inspect [dir]        resolved scene as JSON (dir defaults to .)

  --json                    JSON output (default)
  --all                     include editor-only properties
  --artboard=<name>         one artboard only

push:
  rive push [dir]           build and push the .rev to the bound Rive file

  --project=<id>            project for the first push (a picker chooses
                            otherwise)
  --list                    list your projects and their ids
  --name=<label>            revision history label

ls:
  rive ls                   projects in the current workspace
  rive ls <projectId>       top-level folders (with counts) and root files
  rive ls <projectId> <folderId>
                            one folder's subfolders and files
  rive ls --recent          files opened in the last 30 days

  --all                     with a project id: every file, with its path
  --plain                   print the table; a terminal browses instead
  --json                    one JSON object per line
  --workspace=<id>          list another workspace, this run only

workspace:
  rive workspace            the current workspace and every other one
  rive workspace <id>       switch; your personal workspace until
                            you do

open:
  rive open <fileId>        open the file in the editor, printing its url

  --print                   print the url, open no browser

terminal commands (type while watching):
  s|screenshot [path]       write a png of the window
  p|pause                   toggle playback
  a|artboard [name]         switch artboard, or list them
  f|fit [mode]              switch fit, or show the modes
  z|size                    resize the window to the artboard, and
                            follow it again after a drag
  d|data [path]             write the bound data as JSON
                            (- or stdout for standard output)
  rev [path]                export an editor .rev
  ?|help                    list commands

signing in:
  rive login                --publish, --publish=web, --rev and rive push share
                            this token; anyone who logged in before the CLI
                            write scope must run rive login again
  every other project run   no session, and works offline: the bare
                            watch, --once, --verify, --test, --screenshot,
                            --semantics, --data-dump, --serve, --headless-serve
  standalone commands       no session either -- though update, whoami
                            and doctor do reach the network

exit codes:
  0 ok    1 failure    2 usage    3 not logged in
  6 tests failed    7 service unreachable
